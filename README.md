# 📔 Notebook — Minimalist Notes & Thought Saver

> A fast, lightweight, and modern web application to organize your notes, ideas, and daily thoughts effortlessly.

🌐 **Live Demo:** [fanciful-figolla-eec324.netlify.app](https://fanciful-figolla-eec324.netlify.app/)

---

## ✨ Features

- **⚡ Instant & Lightweight:** Loads instantly with zero bloat or slow dependencies.
- **🎨 Distraction-Free UI:** Clean layout crafted for maximum readability and focus.
- **📝 Easy Note Management:** Quickly create, edit, search, and delete notes on the fly.
- **💾 Auto-Save (LocalStorage):** Your data stays private and persists locally inside your browser.
- **📱 Fully Responsive:** Smooth performance across desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

`HTML5` • `CSS3` • `Vanilla JavaScript (ES6+)` • `Netlify`
